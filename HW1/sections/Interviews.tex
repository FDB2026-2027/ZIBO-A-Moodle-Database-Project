Several interviews were conducted to define the requirements of the Moodle Database system.
In particular, we interviewed:
\begin{itemize}
    \item \textbf{Students:} to understand their main requirements for the student-side functions of the system.
    \item \textbf{Teachers:} to understand their main requirements for the teacher-side functions of the system.
    \item \textbf{Operations officers:} to understand the basic procedures needed to run an information system in a school.
\end{itemize}
