\section{Functional Requirements}
These requirements describe the services and features that this system must provide to its users :
\begin{itemize}
    \item \textbf{FR1:} The system shall allow students, teachers, and operation officers to log in.
    
    \item \textbf{FR2:} The system shall allow students to view their courses and access learning materials.

    \item \textbf{FR3:} The system shall allow students to enroll and unenroll from courses 
    
    \item \textbf{FR4:} The system shall allow students to submit assignments and take quizzes.
    
    \item \textbf{FR5:} The system shall allow teachers to upload learning materials and publish announcements.

    \item \textbf{FR6:} The system shall allow teachers to see the participant students in the course
    
    \item \textbf{FR7:} The system shall allow teachers to create assignments and quizzes.
    
    \item \textbf{FR8:} The system shall allow teachers to manage student grades and results.
    
    \item \textbf{FR9:} The system shall allow operation officers to manage user accounts.
    
    \item \textbf{FR10:} The system shall allow users to access information according to their roles and permissions.
\end{itemize}
