\section{Constraints}

The DBMS application should satisfy the following additional constraints:

\begin{itemize}
    \item \textbf{C1:} Be implemented with MySQL.
    
    \item \textbf{C2:} Client side implemented as a Web application, to guarantee easy management through different devices.
    
    \item \textbf{C3:} Only authorized users shall be allowed to modify information.


 \end{itemize}
