

\section{Non-Functional Requirements}

\begin{itemize}
    \item \textbf{NFR1:} The system shall protect user accounts and academic information from unauthorized access.
    
    \item \textbf{NFR2:} The system shall provide a simple and fluid interface that is easy to use.
    
    \item \textbf{NFR3:} The system shall respond to user requests within an acceptable time.
\end{itemize}
